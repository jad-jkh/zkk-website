# How Jad wants work delivered

- No fluff. Short imperative instructions. Plain steps with links.
- Do not make Jad review everything. Give a short summary per task (what changed, files, 1 or 2 things to spot-check).
- Render and look at pages (desktop and mobile) before saying done.
- Never merge, push to production or change the live site without approval. Work on the fork, draft PRs only.
- Drafts that Jad must send to others: write them out.
- Jad adjusts model and effort per task. Say when a task would be better on a different model.
